# Сквозные тесты Exam Forge

Playwright проверяет студенческий вход и сдачу, восстановление ответа после обрыва связи, кабинет преподавателя, импорт и выдачу кодов группе из 30 студентов, пробное прохождение и создание тренировки из результатов.

## Локальный запуск

Нужна отдельная созданная база PostgreSQL, например `examforge_e2e`. Команды для PowerShell запускаются из корня репозитория.

```powershell
dotnet build ExamForge.sln -c Release
Set-Location e2e
npm ci
npx playwright install chromium
$env:E2E_WEB_SERVER = "managed"
$env:E2E_DB = "Host=localhost;Port=5432;Database=examforge_e2e;Username=postgres"
npm test
```

| Переменная | Назначение |
| --- | --- |
| `E2E_DB` | Строка подключения к тестовой БД. |
| `E2E_WEB_SERVER` | `managed` запускает локальное приложение. Уже занятый порт считается ошибкой. |
| `E2E_CONFIGURATION` | Конфигурация сборки приложения, по умолчанию `Release`. |
| `E2E_PORT` | Порт локального стенда, по умолчанию `5080`. |
| `E2E_BASE_URL` | URL отдельного запущенного стенда. Режим `managed` при этом можно пропустить. |
| `E2E_SKIP_SEED` | `1` читает готовый `.state/seed.json` и пропускает засев. |

Засев добавляет независимые приглашения для студенческих сценариев. `.state/seed.json` и трассы могут содержать тестовые коды. Храните их локально.
