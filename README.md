# Exam Forge

Учебный портал для проведения тестов и контрольных: преподаватель готовит банк заданий, собирает версии тестов, назначает работы и проверяет результаты; студенты проходят работы онлайн по одноразовому коду, общей ссылке или личному аккаунту.

## Возможности

- **Банк заданий**: девять типов вопросов (выбор ответа, короткий/развёрнутый ответ, сопоставление, сборка букв, порядок, пропуски, структура), черновик → публикация, правки создают новые редакции без изменения уже собранных версий тестов.
- **Конструктор тестов**: версии из опубликованных заданий, blueprint-предпросмотр, варианты с перемешиванием по seed, печать листов студента и ключей (A4).
- **Назначения**: контрольная/тренировка, расписание, число попыток, лимит времени на вопрос и на попытку, запрет возврата к прошлым вопросам. Три режима входа студентов: одноразовый код, общая ссылка, логин/пароль.
- **Проведение**: сервер владеет таймерами и состояниями попытки (FSM), автосохранение ответов с ревизиями, корректная обработка обрыва связи и дедлайнов.
- **Проверка и результаты**: ручная проверка с критериями и переоценкой (с историей), ведомость (CSV/XLSX), бумажные работы со сканами.
- **Справочники**: словари (в том числе импорт из PDF), группы, студенты, предметы, лекционные материалы с доступом по правам.

## Технологии

- .NET 10, ASP.NET Core Blazor Web App: кабинет преподавателя — Interactive Server, студент — WebAssembly
- PostgreSQL 17 + EF Core (миграции применяются вручную, без автозапуска)
- Модульный монолит: Domain → Application → Infrastructure → Web (Domain не зависит от UI/EF)
- PdfPig (импорт словарей), ClosedXML (экспорт ведомости), ASP.NET Core Identity
- Без внешних CDN и аналитики; CSP без inline-скриптов; все статические ассеты локальные

## Структура

```
src/
  ExamForge.Domain/          # доменная модель и правила (чистая логика)
  ExamForge.Application/     # сценарии, DTO
  ExamForge.Infrastructure/  # EF Core, Identity, файлы, сервисы
  ExamForge.Web/             # хост: кабинет преподавателя, API, печать
  ExamForge.Web.Client/      # студенческий WASM-клиент
tests/
  ExamForge.UnitTests/       # домен и логика
  ExamForge.IntegrationTests# API и поток студента на TestServer
docs/UI_KIT.md               # дизайн-система (токены, компоненты)
design/                      # токены и HTML-референс оформления
deploy/docker/               # Dockerfile, docker-compose, env.example, deploy.sh
```

## Быстрый старт

Требуется .NET 10 SDK и PostgreSQL.

```bash
dotnet restore ExamForge.sln
dotnet ef database update --project src/ExamForge.Infrastructure
dotnet run --project src/ExamForge.Web --launch-profile https -- --seed-admin <login> <password> "<ФИО>"
dotnet run --project src/ExamForge.Web --launch-profile https
```

Приложение поднимется на `https://localhost:7039`. Строка подключения задаётся в `src/ExamForge.Web/appsettings.json` или переменными окружения.

## Docker

```bash
cd deploy/docker
cp env.example .env   # заполните EXAMFORGE_DB_PASSWORD и EXAMFORGE_HMAC_KEY (64 hex)
docker compose up -d --build
docker compose run --rm app --migrate     # применить миграции
docker compose run --rm app --seed-admin <login> <password> "<ФИО>"
```

Миграции и администратора создают отдельные команды `--migrate` / `--seed-admin` — при старте контейнера база не меняется.

## Тесты

```bash
dotnet test ExamForge.sln
```

191 тест: доменные правила (округление оценок, FSM попыток, варианты), интеграционные сценарии (вход, поток студента, конструктор, печать, авторизация).

## Безопасность

- Секреты только через переменные окружения (`env.example` — шаблон без значений).
- Пароли приглашений хешируются, одноразовые коды показываются один раз.
- Антифорджери на всех изменяющих запросах, CSP `script-src 'self'`, заголовки nosniff/X-Frame-Options/Referrer-Policy.
- Файлы студентов хранятся на диске с проверкой сигнатуры PDF и лимитом размера.
